# AI Work Assistant

Frontend shell for a learning project. The UI covers navigation, auth forms, an assistant chat layout, document selection, and task management. AI, voice, uploads, and automation are left as empty integration points in `lib/ai/`.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — development server
- `npm run lint` — ESLint
- `npm run typecheck` — TypeScript
- `npm run build` — production build
